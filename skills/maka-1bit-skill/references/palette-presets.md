# Palette presets

Choose exactly one palette after choosing the style. Every palette contains one dark and one light RGB color and remains technically 1bit.

1. `olive-terminal` — dark olive `#0b0e08`, pale olive `#bac3a0`; restrained terminal/Game Boy character.
2. `soft-mint` — forest green `#103b2b`, pale mint `#dcefc8`; airy and organic.
3. `classic-mono` — black `#000000`, white `#ffffff`; maximum contrast and print compatibility.
4. `amber-screen` — dark brown `#2a1600`, amber `#f2c14e`; warm CRT terminal character.
5. `cobalt-ice` — navy `#071d3b`, ice blue `#b8dbff`; cool technical character.
6. `plum-paper` — dark plum `#2e102f`, pale pink `#efcfea`; softer editorial character.

Apply the chosen pair to any of the three styles. Do not change the dither method when changing only the palette. Keep the darker color first. A custom two-color pair is allowed only when the user explicitly supplies both colors.
