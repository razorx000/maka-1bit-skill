# 色板预设

选择风格后，必须选择且只能选择一种色板。每种色板都包含一个深色 RGB 值和一个浅色 RGB 值，技术上仍为 1bit。

1. `olive-terminal` — 深橄榄色 `#0b0e08`、浅橄榄色 `#bac3a0`；克制的终端机 / Game Boy 气质。
2. `soft-mint` — 森林绿 `#103b2b`、浅薄荷色 `#dcefc8`；轻盈、有机。
3. `classic-mono` — 黑色 `#000000`、白色 `#ffffff`；最高对比度，适合印刷。
4. `amber-screen` — 深棕色 `#2a1600`、琥珀色 `#f2c14e`；温暖的 CRT 终端机气质。
5. `cobalt-ice` — 藏蓝色 `#071d3b`、冰蓝色 `#b8dbff`；冷峻、技术感。
6. `plum-paper` — 深梅子色 `#2e102f`、浅粉色 `#efcfea`；柔和的编辑设计气质。

任一种色板均可用于三种风格。只更换色板时，不得改变抖动方法。始终将深色放在前面。只有当用户明确提供两个颜色时，才允许使用自定义双色。
